# Código de Conduta — Educa Mais

## Nosso compromisso

Este projeto existe para reduzir a desigualdade educacional. Para isso, a comunidade precisa ser
acolhedora, diversa e segura — especialmente porque tratamos de dados de crianças e adolescentes.

## Comportamentos esperados

- Respeito a todas as pessoas, independentemente de gênero, identidade, orientação, raça, etnia,
  religião, deficiência, idade ou nível de experiência.
- Feedback técnico específico e generoso; crítica ao código, nunca à pessoa.
- Uso de linguagem simples e acessível (o projeto é também material de formação).
- **Zero** dados reais de alunos em issues, PRs, testes ou exemplos.
- Divulgação responsável de vulnerabilidades (ver [SECURITY.md](SECURITY.md)).

## Comportamentos inaceitáveis

- Assédio, discriminação, linguagem sexualizada ou ataques pessoais.
- Exposição de informações privadas de terceiros (doxxing) ou de alunos.
- Uso do projeto para vigilância individual, ranking punitivo ou exposição pública de estudantes.

## Aplicação

Violações podem ser reportadas a `conduta@educa-mais.com`. Toda denúncia é tratada com confidencialidade.
Mantenedores podem remover contribuições, comentários ou acesso conforme a gravidade.
